# Mac 0.3.0-rc.5 账号有效期同步验证

日期：2026-11-10。插件 `xyquant-factors-macos`，版本 `macos-v0.3.0-rc.5`。

OAuth 连接有效期跟随账号到期日；永久账号的连接无固定到期日。账号有效期间续期，会同步仍有效连接和未使用刷新令牌；缩短有效期会同步缩短。账号停用、重置密码和主动撤销仍立即失效，已经过期或撤销的连接不会恢复。访问令牌仍最多 10 分钟，由插件自动刷新，未增加权限范围，也未修改 API Key 的有效期。

客户端不再仅凭缓存的连接到期日拒绝请求，会向服务器刷新并取得最新期限。登录任务在后台先核对已有连接，续期有效时直接完成，不弹出网页登录；网络故障保留本地凭据，不误触发重新授权。

## 已验证

- 服务端 14 项隔离测试通过：新增授权、有效期延长或缩短、永久账号、过期或撤销不恢复、刷新令牌轮换及复用检测、账号隔离。
- 数据库私有副本的迁移演练通过，只同步有效连接及相应令牌期限，不修改账号、权限、API Key 或研究数据。

- Apple 芯片 Mac 上实际启动器版本与 MCP 初始化版本一致，发现 16 个工具，使用临时状态目录，不进行真实授权。
- ZIP 的 25 个成员与插件源文件一致，三个 Skill 保留，四种插件清单版本一致；依赖锁、Python 和依赖归档未变，WorkBuddy 元数据检查通过。
