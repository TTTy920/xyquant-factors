# Mac 0.3.0-rc.4 本地选股归因验证

日期：2026-11-10。插件 `xyquant-factors-macos`，固定版本 `macos-v0.3.0-rc.4`。

策略选股归因已由服务器工具包装改为 Skill 自带的 Python 标准库脚本。脚本在本地校验评分及权重、计算组内排名和名额线、解释主要评分驱动；没有网络请求。Mac 启动器新增 `--selection`，使用随包解释器。三个 Skill 保留，远端选股归因转发入口移除。

## 数据准备

需要本地完整候选组评分明细、组别名额、排序方向及评分规则，输入格式见 [Skill 输入说明](../plugins/xyquant-factors-macos/skills/strategy-attribution/references/input.md)。本版不自动下载服务器评分原始明细。只有策略名和月份、不具备本地数据时，不能完成归因；Skill 应报告缺项。此数据准备边界与本地 Barra 工作流一致。

## 已验证

- 8 项本地行为测试通过，覆盖名额线并列、入选及落选参照股、正负评分驱动、低分优先、缺失维度、部分分组、无记录、无数据、子项掩码、歧义记录和评分不一致。
- 576 组合成评分工作簿与原服务器算法逐结果一致，包含不同名额、排序方向、月份、个股及名单查询、不同权重、子项映射和只有总分的情形；未使用客户评分数据。
- 包含上述 8 项在内的 52 项相关客户端回归通过，工具合同为 16 个客户端工具、10 个远端转发声明。
- 在 Apple 芯片 Mac 上，实际 `--selection` 启动器输出与本地函数一致；CLI 和 MCP 初始化版本一致，工具发现精确为 16 个，不再提供远端选股归因入口。
- 三个 Skill 格式验证通过；完整 ZIP 的 25 个成员与插件目录一致，包含本地脚本和输入说明，四种清单版本一致。依赖锁与原 Python、依赖归档不变，WorkBuddy 配置一致性检查通过。

服务器通过现有工具开关关闭 `explain_strategy_selection` 与 `run_barra_attribution`，保留其他工具；检查公开工具列表及直接调用拒绝，不重启或重新部署应用代码。该开关只限制 MCP，不修改客户账号和授权范围。

## 范围

未重做首次 OAuth、真实文件下载、Intel 实机或 Windows 构建；客户端网络行为沿用既有实现。服务器原始评分文件的自动下载尚未接入，不把此版本描述为只需策略名和月份即可自动完成归因。
