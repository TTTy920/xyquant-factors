# Windows 与 macOS 插件验收 · 0.3.0-rc.6

两个发布包使用相同的因子查询下载、Barra 归因与策略选股归因 Skill。客户端声明 16 个工具。实际查询根据服务端开放状态和当前账号权限执行。

发布时核对以下结果：

- Windows x64 原生构建在 GitHub Actions 的 Windows 2022 运行器执行。检查实际 EXE 的版本、MCP 握手、工具列表、WorkBuddy 入口与两个本地归因命令。
- Mac 包从已锁定的上游文件构建，包含 Apple 芯片和 Intel 的运行环境。测试通过插件入口发现工具并对合成持仓和评分表进行本地计算。
- 从两个发布 ZIP 读取清单，逐文件核对所有 Skill，并比对合成输入的结果。校验值与各自的发布包一起提供。

这些检查使用隔离目录和合成输入。Windows 桌面客户端的人工浏览器登录以及 Intel Mac 实机验收范围另行记录。本版按预发布版分发。
