# Mac 0.3.0-rc.2 预发布验收

日期：2026-11-10。发布目标：`macos-v0.3.0-rc.2`，插件 `xyquant-factors-macos`。

本轮增加策略选股归因 Skill，并把策略目录、介绍、表现、净值统一为 `query_strategy_research`。策略归因 Skill 调用现有服务端 `explain_strategy_selection`；Barra Skill 继续使用本地脚本。Mac 包共四个 Skill，包含原有因子计数，保留最新 WorkBuddy 兼容配置。

## 已完成

- 48 项相关客户端回归通过，覆盖选股解释透传、并列与缺失、严格参数校验、研究查询、导出恢复、只读重试和工具名单。
- 四个 Skill 均通过 Skill 格式验证。
- 在 Apple 芯片 Mac 上使用实际随包启动器启动 MCP，CLI 与初始化均报告 `0.3.0-rc.2`，发现精确的 17 个客户端工具。
- 发现列表包含统一策略查询和选股解释；不再暴露旧四个独立查询及团队查询。两条非法请求在本地拒绝，未请求远端数据。
- 完整 ZIP 通过完整性检查，24 个成员均与插件源码目录一致；四种插件清单的版本一致。四个 Skill 全部包含在安装包内。
- 两种架构的 Python、依赖归档均通过原有 SHA-256 验证，依赖锁未变；本轮只重新生成客户端桥接及其校验清单。
- WorkBuddy 生成配置一致性检查通过，保留 Windows 原版本和 Mac 兼容启动入口。

## 验证范围

本轮没有重做首次 OAuth 登录、真实下载及策略数据查询；已有登录下载流程和服务端部署沿用先前验收。此前服务端统一查询已经通过 70 项隔离回归，以及真实授权下的目录、组合详情、净值翻页与旧入口关闭检查；这些检查不记作本轮重新执行。

Intel 架构只验证了归档及其校验值，未在 Intel 实机运行。未构建或测试 Windows 更新，未重部署服务器。Windows CI 本轮未运行。此为预发布版，不能视作全部客户设备、全新用户安装或全部登录场景的验收。
