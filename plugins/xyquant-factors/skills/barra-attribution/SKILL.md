# Barra 组合风格归因

使用已连接的 XYQuant MCP 工具 `run_barra_attribution`，直接提交组合持仓。若当前工具列表中找不到它，提示用户检查 XYQuant 远程 MCP（`https://47.103.215.251/mcp`）的连接状态。通过网页登录时需要 `research:read` 权限。

## 准备持仓

从用户提供的表格或消息中提取 `日期`、`股票代码`、`持仓比例` 三列。仅有净值、收益率或股票名单时，请用户补充所需月份的逐股持仓和权重。

- 每个组合每月取一份月末持仓快照。日期支持 `YYYY-MM` 或 `YYYY-MM-DD`，同月内的日期都按该月的月末处理。多个组合分别调用。同一组合、同月、同股只能有一条记录，确认重复行代表可相加的分仓后再合并。
- 股票代码保留六位数字及交易所后缀 `.SH`、`.SZ` 或 `.BJ`。持仓比例使用小数，例如 `60%` 填 `0.6`。沿用实际权重，即使因现金或杠杆而合计不等于 100%。若权重单位不明确，先确认。
- 只把这三列放进 `holdings`。持仓较多时按完整月份分批，每个组合的同一个月放在同一批中。

两只股票的示例调用参数如下。

```json
{
  "holdings": [
    {"日期": "2020-09", "股票代码": "000001.SZ", "持仓比例": 0.6},
    {"日期": "2020-09", "股票代码": "600000.SH", "持仓比例": 0.4}
  ]
}
```

## 展示归因

按服务返回的月份和十个因子列展示两张表。

- **月末组合暴露**按持仓月标记。每个值是各股票该因子暴露按实际持仓权重的加总，展示为数值。
- **月度风格收益贡献**按收益发生月标记。每项贡献等于上月末组合暴露乘以本月因子收益。例如 9 月末持仓对应 10 月贡献，贡献值 `0.012` 表示对当月收益贡献 `1.20` 个百分点。若服务缺少下月因子收益，就展示该期已有的暴露，注明相应月份的贡献缺失。

用户询问收益驱动时，按当月已返回的因子贡献指出主要拉动项和拖累项，保留正负号及月份。归因结果限于这两张表。工具报错时按返回信息说明需修正的持仓、权限或数据问题。
