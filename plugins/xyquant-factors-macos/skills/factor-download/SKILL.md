# 因子查询与浏览器下载

使用客户端已连接的 XYQuant 数据 MCP。需要登录时，提示用户在客户端连接 XYQuant，在打开的 XYQuant 网页用自己的账号授权。密码只在网页输入。没有连接时保留查询条件，说明缺少连接；不要索要密钥、读取浏览器凭据或自行发起登录程序。

## 找因子与查询数值

- 名称不明确时，用 `list_factors` 搜索因子库，按返回的标识用 `get_factor_info` 查看定义与可用日期。策略的综合得分、子因子与公共因子库是不同资料，不用同名因子代替。
- 用 `preview_factor` 查询指定因子、起止日期和股票代码。日期格式为 YYYY-MM-DD，股票代码保留交易所后缀。缺少必要的范围时先澄清；仅在用户指定全市场时省略股票限制。最多展示实际返回的 50 行，保留空值。需要全量统计时先取完整文件。

## 导出并交给浏览器

1. 用户要求完整数据时，按选定的因子、日期、股票条件调用 `create_export`。为每个新请求生成一个 UUID 作为 `request_id`。提交结果不明时，使用原 `request_id` 调用 `get_export` 核查；若需重试，复用原编号和相同条件。
2. 从返回的 `id` 取得任务编号，用 `get_export(job_id=…)` 查询；用任务编号或请求编号二选一。等待时按服务端建议退避，已提交的任务不要重复创建。找回以前的导出用 `list_exports`，只展示当前账号的结果。
3. 状态为 `ready` 且文件仍可下载时，给出任务编号、文件名及返回的到期时间，附上[因子网站](https://47.103.215.251/factors/)。请用户用**同一个账号**登录，在“最近导出”找到任务并点击“下载”。单因子为 Parquet，多因子为 ZIP；浏览器决定保存位置。需要放进某个项目时，用户可以在浏览器中选择该文件夹。
4. 云端就绪只表示“可以下载”，不要报告文件已写入用户电脑。不要把需要令牌的地址当成公开链接，不向浏览器地址添加令牌，不调用本机桥接下载工具。过期、权限不足或导出失败时按实际状态说明；重新导出须符合用户意图。

本技能只使用因子目录、说明、预览和导出数据。Barra 归因交给本地的 Barra Skill；不上传持仓，不用远程分析工具代算。
