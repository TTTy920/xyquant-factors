# 本地策略选股归因

使用 [本地计算脚本](scripts/attribute.py) 完成评分校验、组内排序、名额线判断和驱动解释。计算在本机完成，不调用远端 `explain_strategy_selection`，也不把评分明细上传服务器。

## 准备数据

需要用户指定策略、月份及可选股票，以及本地评分明细和对应的分组规则。规则必须包括各组名额、排序方向；解释评分驱动时还需要评分项、正权重及可选子项映射。不能从策略名称猜测规则，也不能把综合分当成完整评分明细。

输入格式见 [本地输入说明](references/input.md)。已有 Excel 或 CSV 时，可在本机转换为该 JSON 格式，保留列名、日期、空值和原始精度。本版不自动下载服务器的评分明细；没有合法取得的明细或规则时说明缺项，停在数据准备环节，不改用服务器归因结果。

月份使用 `YYYY-MM`；股票代码带 `.SH`、`.SZ` 或 `.BJ`。查询最新一期时根据本地明细实际覆盖选择月份。查询个股时保留 `symbol`；查询分组名单时省略，不擅自扩大查询范围。

## 本地运行

完整 Mac 插件使用随包解释器，无需安装系统 Python：

```sh
/bin/sh "<插件根目录>/bin/factor-bridge" --selection "<本地输入.json的实际路径>"
```

仅复制 Skill 时，可使用已有 Python 3 运行 `scripts/attribute.py "本地输入.json"`。脚本仅依赖标准库，没有网络请求。读取标准输出中的 JSON 结果；校验失败时更正本地数据或规则，不跳过校验继续推算。

## 解读结果

先说明策略、查询月份及实际明细日期。将结论表述为“按当期评分和组内名额推算的选股结果”，不是实际交易记录，也不是重新运行回测。

- 入选或未入选：结合组内名次、名额、名额线及边界参照解释。
- 名额线并列待定：保留同分股票数和待定名额，不按代码替策略决定入选名单。
- 当期明细无记录：不能据此断言触发了某条过滤规则。
- 缺失分组、当月无数据：明确覆盖，不补零或推算缺失名单。
- `综合分差贡献` 是评分差异，保留正负号，不能称为收益贡献或百分比；只展示主要项，不能宣称完整分解。
- 两股有效评分项或子项不同：只展示本股评分依据，不强行逐项比较。

缺少评分维度时只解释综合分和排名，不补造驱动因素。多个月分别计算，保留各月规则、分组和边界，不混用参照股。用户要分析组合风格或因子收益贡献时，使用同包 Barra 归因 Skill。
