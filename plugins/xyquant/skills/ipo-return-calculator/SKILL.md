# A 类网下打新测算

使用 scripts/calculate.py 执行计算。Python 3.10+，依赖 pandas、openpyxl，见 requirements.txt。用户明确指定本地 Excel 时直接读取；其他情况先按 [MCP 取数](references/mcp-data.md) 通过当前授权取得 IPO发行数据.xlsx，再把返回的本地绝对路径传给 --input，不以项目中的旧下载文件代替本次查询。用户明确要求寻找本地文件时，在当前项目查找 IPO发行数据.xlsx，多份候选需确认目标。

默认入围率为 90%。完整测算使用原代码规模列表 1、2、3、5、10、15、20、25、30 亿元。单一规模问题沿用对话指定值，未指定则使用 2 亿元并披露假设。

    python <skill目录>/scripts/calculate.py --input <Excel绝对路径>
    python <skill目录>/scripts/calculate.py --input <Excel绝对路径> --sizes 10 --year 2025 --board 科创板 --details

--valid-rate 使用 0 到 1 的小数，--sizes 单位亿元。脚本输出 JSON，收益率是小数，回答时乘以 100 并加百分号。默认直接回答关键数据；用户要求明细时列出个股，按需展示发行价、首日均价、中签率、有效申购额和收益金额。只有用户要求保存时使用 --output 写入 JSON 文件。

## 原始代码口径

发行统计包含所有板块，按上市年、月、板块汇总股票代码计数和募资总额。收益测算剔除北交所。
有效申购额为 min(网下申购上限万股 × 10000 × 发行价格, 账户规模亿元 × 100000000)。
首日涨跌幅为上市首日均价 / 发行价格 − 1。
收益额为有效申购额 × 入围率 × A 类中签率百分数 / 100 × 首日涨跌幅。
收益率为收益额 / 账户规模元。逐只加总，无复利或年化。
缺失收益字段时保留个股空值，汇总沿用 pandas sum 跳过空值，展示可测算数以解释覆盖情况。
月度收益保留原代码的特例，即缺少 2025 年 2 月时补零；有年份筛选时仅在 2025 年筛选下补该行。
年度分板块收益按上市年份和上市板汇总。

脚本在原公式外增加了输入校验、筛选、JSON 输出与收益金额明细。不得将字段缺失直接解释为实际收益为零。数据来自本次 Excel 快照，回答时明确样本范围及参数。
