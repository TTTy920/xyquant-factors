# 同日合成数据契约

- 唯一输入是本 Skill 在既有 OAuth 下载流程中校验的同日 MCP 多因子 ZIP。每个启用的唯一因子 ID 对应一个 `<ID>.parquet`，真实列为 `date`、`stock_cd`、`alpha`（数值）。无关文件、错误日期、日内时间、不符范围、重复日期/代码键、失败校验均拒绝；不会把结果中的首批 50 行当截面。不会解包输入路径，归档压缩体积最大 32 MiB，解压成员总大小最大 128 MiB，每因子最多 100000 行。
- 默认池为实际授权导出里，规范化后符合 A 股代码规则的证券并集（可识别沪、深、北）；不独立证明该日完整在市名单。对指定池，仅按请求代码与授权导出计算。每因子有效数按有限数值统计；共同样本为所有启用因子有效代码的交集。空值、不存在与无穷值只作为缺项，不填零。负数是正常因子值。不猜测被排除是因为未授权、未上市还是数据缺失。
- 所有分位以共同样本为分母、并列使用平均秩；最低共同样本默认 20 只。完全相同的因子为 50 分，相关性为空。归一权重用精确比值，CSV/JSON 的得分展示为十进制数值；不输出复合得分排名。
- `metadata.json` 记录规则版本、实际截面日、计算池、缺失计数、MCP 导出文件 SHA-256、方向和可复算权重、相关系数，以及可选的单股得分；不存票据。历史定权还记录报告 SHA-256 和筛选口径，见 [RankIC 权重契约](rankic-weights.md)。`scores.csv` 只有 `stock_code,score` 两列，整池按代码升序；`report.md` 是计算说明。共同样本不足或指定股票不能打分时不生成 CSV。
- `--stock` 仅控制交付行，不改变文件读取或分位分母。查询单股只导出该股。自定义池有股缺数据时原因是「缺有效因子或本次未返回」；单股不在这个池时明确报不在指定池。结果是客户项目的本地研究数据，不提交第三方新闻搜索或写回因子库。
