# 组合收益归因

使用本地测试通过的原版计算。两个入口只决定持仓来源；股票收益重建、全市场因子收益估计、Barra、Brinson及累计连接共用同一套原版脚本。

## 选择持仓入口

- 用户明确使用自己的组合并提供持仓：`--source user --holdings <文件绝对路径>`。缺持仓先补充，不改用同名预置策略。复用本次对话已经提供的信息和文件。
- 用户选择300增强、xgb500增强、xgb1000增强或xgb2000增强：`--source preset`。300增强默认对应沪深300、月频；三个XGB分别对应中证500、1000、2000、周频。区间和方法沿用用户要求。
- 对象不明确时询问使用自有组合还是预置策略，一次补问缺失的名称、基准、日期、频率和持仓。默认两种方法；用户明确方法时只运行对应方法。

持仓支持Parquet、CSV、XLSX长表：`date, stock_code, weight`，也接受日期、股票代码、权重等对应列名；日期是快照日期，股票带交易所后缀，权重用小数。现金仅支持CNY、CASH、现金。入口不归一化权重、不补日期和收益。基准可选原包四个指数；客户另有基准权重时增加 `--benchmark-holdings <文件绝对路径>`，格式同持仓。其他基准需要客户提供。

## 服务器取数与本地缓存

1. 调用 `query_stock_data(dataset="catalog")`，读取返回的 `original_attribution`。它列出原版数据版本、策略与基准、频率和覆盖日期。策略展示工作簿不是持仓来源。若没有该数据类别，说明需刷新MCP连接或服务器尚未提供，不能换用现成因子收益率凑数。
2. 先检查项目已有缓存，版本和清单校验值使用目录实际返回值：
   ```text
   python3 <Skill绝对路径>/scripts/download_original.py status --project <已有项目绝对路径> --data-version <data_version> --manifest-sha256 <manifest_sha256>
   ```
   返回ready就复用 `data_root`，不重复导出或下载。缺缓存时，以UUID `request_id` 和目录版本调用 `query_stock_data(dataset="attribution_bundle", data_version=..., request_id=...)`；此完整数据包不传日期或股票筛选，保留原版全市场回归样本。网络重试复用原编号。用同工具仅传 `job_id` 查询，按建议或每5秒等待，直到ready/failed。
3. 把ready任务JSON作为数据通过不回显的进程标准输入传给下载脚本：
   ```text
   python3 <Skill绝对路径>/scripts/download_original.py save --project <已有项目绝对路径>
   ```
   沿用MCP授权，无需再次网页登录。下载凭据不写入文件、日志、聊天或命令行参数。凭据到期时查询同一任务后重试，已过期任务用新请求编号。脚本校验压缩包、清单和逐文件SHA-256，返回可复用的绝对 `data_root`。

服务器只提供公开原始数据：股票日收益、流通市值、回归合格标记、十风格暴露、历史行业、原包日历、四个策略及基准权重。数据保持原包格式，GitHub插件包不附行情或持仓数据。客户持仓和权重留在本地，不上传；全市场横截面回归及归因全部在本地运行。本流程不读取现成因子收益率；`query_barra_data` 的独立查询和下载功能仍可使用。

## 本地执行与交付

先查看已下载数据的清单：
```text
python3 <Skill绝对路径>/scripts/entry.py inventory --data-root <下载返回的data_root>
```

预置策略：
```text
python3 <Skill绝对路径>/scripts/entry.py run --source preset --data-root <data_root> --portfolio 300增强 --benchmark 沪深300 --start 2025-01-01 --end 2025-02-28 --frequency monthly --method both --output-root <项目内结果目录绝对路径>
```

自有组合：
```text
python3 <Skill绝对路径>/scripts/entry.py run --source user --holdings <用户持仓绝对路径> --data-root <data_root> --portfolio <组合名称> --benchmark 沪深300 --start YYYY-MM-DD --end YYYY-MM-DD --frequency monthly --method both --output-root <项目内结果目录绝对路径>
```

入口把自有持仓转换为原版权重和快照，临时数据位于结果根 `_inputs/`，再调用原版attribute.py。数据格式见 [原版数据约束](references/data-contract.md)。原包策略主要覆盖2025年，市场与暴露至2026-01-30；完整周期也受日历边界限制。先读取下载数据中的 `数据说明.md` 和 `data_quality.json`。部分全年区间有已知收益或暴露缺口，最终以本次运行校验为准；失败时如实报告，不能填零、删除股票重配权重、缩短失败方法区间或切换数据来源。

完成后读取本次report.md、metadata.json及 [对话报告](references/conversation-report.md)，按原版格式在对话中交付分析和表格，Excel作为附件。partial_success只交付完整成功的方法，说明另一方法的缺口。

## 共用计算口径

- 一套数据供两个方法共用：股票日收益、日度基准、原频率组合持仓、日度十风格暴露/流通市值/合格标记、月度行业、交易日历。周/月收益从日简单收益连乘减1；缺一个日收益则该股票区间收益缺失，不能当作0。
- 期初股票权重分别归一化；剔除显式现金并报告；不支持负权重。只支持实际持仓快照具有的频率，不用未来持仓倒推、不给组合或基准任意 ffill。
- 行业逐股票按日期 ffill 到期初，只使用此前最近已知的分类；不能 bfill。初次历史分类之前仍缺失并报错。十风格暴露不采用行业填充规则。
- 两个方法使用同一份交易日历、相同的期初/期末和重建收益。周为周一至周日所在交易周，月为自然月；完整周期按该周期实际交易日判断。请求范围内不完整的周期排除，并说明有效交易区间。日历需额外覆盖请求前后周期以确认边界。
- 重建收益是假设期初股票静态持有一期的结果，未包含期中交易、现金收益和费用，不等于实际产品净值。累计均使用 `C_t=(1+Rb_t)*C_previous+Vp_previous*c_t` 连接，合计对应两者复利收益之差，不是净值比的几何超额。两种归因的贡献不能相加。

## 方法与解读

Barra：每期用全市场期初合格股票的十风格加截距，对当期区间收益做横截面WLS，目标权重为流通市值平方根。不先按持仓筛选回归样本，不重新标准化已有暴露，不直接累加日因子收益替代周/月回归。风格贡献为期初相对暴露乘当期回归系数；累计时额外保留未解释收益与重建超额核对。行业未进入回归，未解释项不是纯Alpha。原始算术累计同时保留为辅助列，不能与连接累计混用。

Brinson：配置为 `(wp-wb)*(rb-Rb)`；选股（含交互）为 `wp*(rp-rb)`。纯选股与交互另列供核对，不再加到两项合计上。基准未持有的行业以基准整体收益作为参考，配置为0，贡献计入选股（含交互），明确该约定；组合未持有的行业不归入选股。行业内选股仍可能包含市值、价值、动量等风格收益，不直接称为纯Alpha。

- 结论：明确主要收益来源和拖累，以及两种视角的一致或不同之处。结论限定在本次数据区间，不编造宏观行情原因、交易行为或因果关系；不足12期明确样本短，不能将正贡献期数外推为长期胜率。

数字默认保留三位小数；收益率用%，贡献用百分点，暴露保留模型单位。不照搬参考报告中的年份、机构署名、数据来源或结论。参考材料仅提供分析结构，所有数字必须来自本次结果。
