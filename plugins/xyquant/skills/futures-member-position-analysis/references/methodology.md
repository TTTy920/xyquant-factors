# 拥挤度与一致性：现行策略定义

依据现行独立副本的 `params.py`、`signals.py`、`build_signal_tables.py`、`weekly.py`，以及金融/商品会员持仓基础数据 notebook，于 2026-11-20 核对。后续改版应重新核对。个别源码注释与函数体不一致，以下以实际执行的函数体为准。

## 拥挤度原始因子

先筛选会员，再计算 `crowdedness=Σ(L_m−S_m)/Σ(L_m+S_m)`，不是会员人数占比、集中度或 HHI。正负表示被选中会员合计净多/净空偏向，不直接代表交易方向。“套保/非套保”只是代码筛选标签，不能据此确认会员真实业务身份。

记品种成交 V、单边持仓 OI，会员成交 V_m、多空持仓 L_m/S_m。排名交集并不代表全市场所有账户。

| 因子 | 保留进入计算的会员 |
|---|---|
| crowdedness_1 | 当日成交、持买、持卖排名按会员名内连接；`V_m/(L_m+S_m) >= V/(2×OI)` |
| crowdedness_2 | 当日排名三表内连接；`abs((ΔL_m+ΔS_m)/V_m) <= abs(2×ΔOI)/V` |
| crowdedness_3 | t−2 至 t 交易日窗口，会员在每类排名中出现至少 2 次，再按日期合并；会员指标 `Σabs(ΔL_m+ΔS_m)/ΣV_m` 不低于品种阈值 `2×Σabs(diff(OI窗口内))/ΣV窗口内`。然后按会员合并记录最后一条的净持仓和双边持仓，分别求和后相除。 |

三个筛选不等式方向不同。方法 3 最多含三个交易日，“出现至少两次”不等于连续三天；复算须核对 API 日期顺序、缺失记录和窗口内差分。

## 拥挤度交易信号

先作 `smooth` 日均值（min_periods=1），再对平滑序列作 `lookback` 日滚动 30%/70% 分位（min_periods=10，含当日）。原始方向：高于高带且最近 `price_window` 个收盘价差均严格为正，记 −1；低于低带且这些价差均严格为负，记 +1；其他为 0。价格不变不计连涨或连跌。

按位置丢掉前 `lookback` 行，之后按 `fill` 设置延续最近非零仓位，最后才按 `reverse` 取反。首个非零前仍为 0。当前所选品种没有额外覆盖 trim；不能按日历天数删行。已交付交易信号不要再次取反。

## 一致性原始因子

金融期货对当日可交易合约的会员多空持仓分别汇总，内连接后相减；商品期货使用主力、次主力两个合约。不能把没有双边共同记录的会员擅自补零。

在相关性窗口内剔除有缺失的会员，按当日净持仓从小到大排序：`top` 为净持仓较低一端，通常偏净空；`bottom` 为较高一端，通常偏净多，但两端不保证分别全为负、正。

- `topN_avg_Ld`、`bottomN_avg_Ld`：相应会员**净持仓水平序列**的 Pearson 相关矩阵上三角均值，不含对角线；不是持仓增量相关性。
- `topN_slope_Ld`、`bottomN_slope_Ld`：所选会员净持仓合计对窗口内 0…L−1 的线性拟合斜率。
- `lb` 是基础相关性/斜率窗口，`lookback` 是信号分位窗口，均以观测交易日行数计算。

## 一致性交易信号

TA/BA 为 top/bottom 平均相关系数，TS/BS 为两端斜率。每个量的高低带均为其自身、信号 lookback 窗口的滚动 70%/30% 分位（min_periods=10）。

| 因子 | 原始信号 |
|---|---|
| ls_avg_top | TA 高于高带：+1；低于低带：−1 |
| ls_avg_bottom | BA 高于高带：+1；低于低带：−1 |
| ls_bottom_resonance | BA 高于高带且 BS 高于高带：+1；否则 0 |
| ls_both_resonance | 上述 bottom 条件：+1；TA 高于高带且 TS 低于低带：−1；否则 0。若两组同时满足，原函数后写入的 −1 覆盖 +1。 |
| ls_rs_composite | `RS=BA×BS−TA×(−TS)`，RS 高于自身高带：+1，低于低带：−1 |

按 lookback 丢掉前若干行，再延续仓位、最后取反；当前一致性参数均不取反。此环节没有拥挤度那样的额外价格连涨/连跌过滤。

## 合成、缺失与净值

- 双因子品种 `position=(crowd_signal+ls_signal)/2`；CU、M、RB 直接使用一致性，不再除以 2。
- 因子值某天为 NaN，不等于因子文件未覆盖该日。前者按原分位比较、持仓延续处理，不能额外把延续仓位打成零；后者在双因子对齐时形成缺失，现行净值对缺失最终仓位填 0。分析仍应暴露覆盖不足，不把缺失称为真实中性观点。
- 整路因子文件缺失时，原构建函数可能退化为单因子。复现双因子策略前要核对必需文件、字段和末日，不能把退化结果当成标准双因子组合。
- 品种固定等权；基准同品种等权做多；空闲资金收益 0，历史未上市份额保留在原分母内。
- 净值收益使用主力连续开盘价前复权 `prev_close_ratio`；拥挤度原始行情使用的 `prev_close_spread` 不应直接替代净值收益序列。
- t 信号对应收益 `position_t×(open[t+2]/open[t+1]−1)−0.000023×abs(position_t−position[t−1])`，当前记在 t+2 实现日。品种等权后单利累加，不复利。
- 会员排名包含会员名下客户等持仓，不等于会员自营观点，不能据此识别具体账户身份或交易动机。

## 当前因子归因还需补充的字段

1. 品种、信号形成日、crowd_signal、ls_signal、combined_position，以及是否已取反/延续持仓。
2. 品种主力开盘收益、收益实现日、换手和费用分摊口径。
3. 解释信号触发另需原始因子、滚动分位带、价格过滤、数据覆盖状态；解释哪些会员驱动一致性另需会员净持仓窗口、两端名单、相关矩阵和斜率。

可选原始文件通常为 `crowd_{品种}.xlsx`、`ls_{品种}.xlsx`，交易信号表可能为“股指期货每日信号.xlsx”“商品期货每日信号.xlsx”。它们不是当前两张净值表的内置工作表，只有实际获得后才可使用。
