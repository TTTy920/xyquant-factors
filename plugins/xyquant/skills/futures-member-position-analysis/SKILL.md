# 期货会员持仓策略分析

用户要求计算时调用后端实际取数计算，不只解释方法。skill 包含可执行计算脚本和 MCP 服务入口；数据访问凭据由服务端私有配置提供。本 skill 不负责重新选参、交易或上传。

## 优先处理实时计算

用户问“某品种当前拥挤度/指标1/历史分位”时调用 `compute_futures_crowding`，输入品种代码或中文名，日期省略即最新完整交易日。默认返回近60、120、250个交易日分位；用户指定窗口则传入 windows。

用户问“最新热力图”时调用 `get_futures_member_heatmap`，默认20个交易日、两端各5家，并展示工具返回的图片。商品默认选目标日主力的**同一合约**回看，沿用原商品热力图；用户要求一致性策略口径时传 `scope="strategy"`，改用每日主力+次主力。指定合约时传 contract，不擅自换成其他合约。金融品种默认全合约汇总。

两个结果使用同一天比较；若工具实际日期不同，明确差异，不称为同日结果。返回原始指标1数值、实际日期、每个窗口的有效样本数和百分位，说明分位数含当日、未平滑；例如工具给出0.82才可表述“约第82百分位”。窗口有缺失时注明有效样本数，不能冒称完整窗口。热力图存在会员分组重叠、剔除不完整会员或相关系数不可计算时，同步说明工具返回的这些限制。

MCP 工具未注册但有服务端计算环境时，可按 [references/live-tools.md](references/live-tools.md) 执行固定脚本。没有数据权限时明确尚未接通，不用缓存截图、组合净值或估计数冒充当前结果。凭据、环境、内部日志和私有文件不作为回答内容；只返回计算结果和图片。仅管理员负责配置后端，不能让普通调用者通过工具传入账号、代码或文件路径。

## 数据与分析范围

通过平台文件工具定位两个固定名称的 Excel，不按文件名判断更新日期：

| 文件 | 组合 |
|---|---|
| 股指期货会员持仓策略净值.xlsx | IH、IF、IM 固定各 1/3 |
| 商品期货会员持仓策略净值.xlsx | AG、CU、FU、M、MA、RB、TA、V 固定各 1/8 |

“净值”表含“日期、策略净值、基准净值”三列。以最后有效日期判断截止日，不默认数据已到今天。逻辑目录为 `/mnt/factor-platform/state/skills/宋子钰/策略`，SFTP 入口为 `/skills/宋子钰/策略`；后者不是分析服务的本地路径，使用平台注册的数据源或部署方提供的映射。

只有这两张净值表时，可比较区间收益、超额、回撤与曲线表现，不能反推会员名单、当日仓位、因子分歧或分因子贡献。

解释拥挤度、一致性和具体品种方向时，读取 [references/methodology.md](references/methodology.md)。静态策略参数不能代替当日观测。实时工具返回原始指标1和会员相关性图，不自动代表按品种参数选定的拥挤度因子或最终交易信号；当前策略方向仍需相应因子和信号明细。

## 保持现行口径

- 单利净值为 `NAV=1+Σr`。区间收益是净值差，以区间开始前最后一个观测为基点；完整序列起始资金基点为 1。不默认使用 `pct_change`、净值之比或 CAGR。
- 超额是策略区间收益减基准区间收益，不是策略净值除以基准净值。
- 组内固定品种等权，基准为同品种等权做多。空仓、未上市或无可用收益的份额按现金处理，不重新分配到其他品种。
- 双因子品种将拥挤度、一致性各按 1/2 合成；CU、M、RB 只有一致性。±0.5 信号是半仓，不能取符号后视为满仓。
- 净值已扣 `0.000023×|仓位变化|` 的单边手续费，不重复扣费。该费用不代表包含滑点等额外执行成本。
- T 收盘信号对应 T+1 开盘至 T+2 开盘收益，导出按 **T+2 收益实现日** 标记；净值日期不是信号形成日。
- 拥挤度高低不直接等于买卖方向，要结合价格过滤、持仓延续和品种取反参数。一致性衡量所选会员净持仓序列的相关程度，也不直接等于看多或看空。

## 如何回答

先给文件、实际截止日和分析区间，再围绕问题给结论。比较两类组合时对齐共同区间并说明各自历史长度，不把无记录日补成零收益。周度收益以本周首个观测前的最后观测为基点。

“净值比例最大回撤”单独标注，不冒称与原单利回测引擎的回撤定义相同。未经核对，不声称年化、夏普等与原报告一致。

有分因子信号可描述同向、分歧或抵消，但这不等于收益归因。归因还需要品种收益、实际仓位及费用分摊口径；合成后换手费用不能简单等分为两个独立策略费用。

缺少明细时明确：“当前净值文件可验证表现，无法确认拥挤度/一致性对该区间的单独贡献。”列出需要补充的字段，不用市场故事填补证据。

## 定量辅助

环境已有 Python 和 openpyxl、且取得可读的本地文件时，可执行：

```bash
python scripts/analyze_nav.py /path/to/股指期货会员持仓策略净值.xlsx --start 2026-11-09 --end 2026-11-13
```

脚本用于本流程导出的完整历史表，只读数据，输出单利区间收益、超额和净值比例回撤；不加入未经核实的年化假设。若输入是截取片段、分析区间又缺少前置观测，应先取得实际基点，不默认该片段从 1 起算。不能执行时，用平台分析工具按相同口径处理，不自动安装依赖。相对路径以本 skill 目录为基准。
