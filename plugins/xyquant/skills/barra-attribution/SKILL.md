# Barra 组合风格归因

使用 [本地计算脚本](scripts/attribute.py) 处理用户提供的月末持仓、原始个股风格暴露和月度纯因子收益。输入文件保存在当前项目中。缺少原始数据时列出所需月份与字段。

## 准备本地输入

每个组合单独计算。从用户给出的持仓中提取月份、股票和实际权重；同一月份取一份完整的月末快照。有来源明确的分仓时可先合并同股记录。保留六位股票代码及交易所后缀，百分数换为小数，例如 `60%` 写作 `0.6`。保留现金和杠杆造成的实际仓位。

脚本接收一个 UTF-8 JSON 对象，下面三个键的值都是行数组。这是脚本的本地输入格式。

| 键 | 一行的含义 | 字段 |
| --- | --- | --- |
| `holdings` | 一个月末的一只持仓股票 | `日期`（YYYY-MM 或 YYYY-MM-DD）、`股票代码`、`持仓比例` |
| `stock_exposures` | 一只股票在模型当月最后交易日的十项暴露 | `月份`（YYYY-MM）、`股票代码`、十个因子列 |
| `factor_returns` | 收益发生月的十项纯风格因子收益 | `月份`（YYYY-MM）、十个因子列，收益用小数 |

十个因子列为 `Size`、`Beta`、`Momentum`、`ResidualVolatility`、`NonlinearSize`、`BookToPrice`、`Liquidity`、`EarningsYield`、`Growth`、`Leverage`。同一个月的个股暴露应来自同一月末交易日。模型月收益表每月采用最后交易日的整行月收益值。

## 计算与展示

定位本 Skill 的目录，使用 Python 3.9 或以上运行脚本。Windows 也可使用 `py -3`。读取标准输出中的两张 JSON 表。

```text
python3 "<Skill目录>/scripts/attribute.py" "<本地输入.json>"
```

- **月末组合暴露**按持仓月展示。每项暴露等于各只股票的实际持仓权重乘以其因子暴露后加总。若非零持仓缺少某项暴露，按脚本提示补充原始数据。
- **月度风格收益贡献**按收益发生月展示。每项贡献等于上月末组合暴露乘以当月因子收益。9 月末持仓对应 10 月的贡献，贡献值 `0.012` 表示贡献 1.20 个百分点。缺少下一自然月的收益行，或该行有因子值为 `null` 时，保留持仓月的暴露，并向用户注明哪一期贡献缺失。

用户询问收益驱动时，依据本地计算结果说明当月主要拉动项和拖累项，保留正负号和月份。
