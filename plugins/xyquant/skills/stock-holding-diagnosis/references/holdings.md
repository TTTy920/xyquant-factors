# 按可得数据展示持仓

通过已授权的 XYQuant MCP 取得归因目录和数据包；不另猜接口，不使用其他账号或 SSH 补权重。在当前授权目录版本和清单 SHA-256 固定的前提下，诊断程序独立校验用到的目录、快照及各策略权重文件；不会因策略 A 或无关市场文件缺失而隐藏策略 B 的可用结果。各策略以 `--as-of` 为截止，周/月频各用自己的快照，不要求同日。

| 状态 | 可展示的内容 | 不能推断 |
|---|---|---|
| `compared` | 最近两期完整快照的日期、持仓/未持有、股票仓位内占比和百分点变化 | 不是实际交易，也不保证是连续调仓期 |
| `no_comparable_previous` | 一期完整快照；其日期、持有状态、股票仓位内占比 | 不补上期，不算变化 |
| `reported_only` | 已校验权重文件中唯一且为正的记录，标为「未确认完整的原始记录」 | 不转成占比，不当作完整快照，不算变化，不进入已验证持有统计 |
| `catalog_only` | 目录里的历史覆盖日期、频率 | 不知道这只股票是否持有，不能写零 |
| `no_verified_snapshot` / `not_available` | 没有可核验的快照或记录 | 同样不能写成未持有 |

只有稀疏正权重表与快照有效标记、股票权重合计吻合，并且目标股票没有记录时，才能记为该期未持有（`0%`）。如果较新的快照不完整但有较早的完整快照，说明回退日期；较新正数记录如可展示应单列，不能和旧占比比较。已被源数据明确标记无效或目标股票键重复的快照，不把对应记录解读为已持有。

原始 `weight` 列的数值**不是统一的小数比例**。如实保留为 `raw_weight`；展示的 `weight` 是原始值除以同一快照已核对的股票持仓合计 `equity_total`，与归因引擎的股票权重口径一致，不含现金，也不假定原始值记的是金额还是股数。`change_pp` 用两期占比之差乘 100，不直接对原始值做百分点运算。没有可核对分母时，只能展示 `reported_raw_weight`，不能报百分比。

## 在已下载数据之外传入目录日期

`--context-stdin` 只接收无凭据的 MCP 持仓目录，不能附加 `news`。`holdings_catalog` 使用本次 `query_stock_data(dataset="catalog")` 返回的 `original_attribution` 中这三个字段：`data_version`、`manifest_sha256`、`portfolios`。每个 `portfolios` 项只保留 `name`、`first_date`、`last_date`、`frequencies`。

```text
{"holdings_catalog": {"data_version": "...", "manifest_sha256": "...", "portfolios": [...]}}
```

版本和清单如已通过命令行传入，目录元数据须与之相符。历史查询不会把截止日之后的目录末期当可用快照；如果目录覆盖跨过截止日而无文件，只报不能确认截止日前的最后一期。目录日期或零条可用记录都不改变四因子持有判断。
